Local Installation & Activation
Run ChangaLab on your own server

This guide covers installing ChangaLab on a local machine or any standard web server (VPS / shared hosting with SSH). It mirrors the official ViserLab process and adds the license activation step required to run the script.

For a cloud, zero-setup option, see Run on GitHub Codespaces.

The purchase code (license) is valid for one domain/URL only. Activate it on the correct URL to avoid issues.
Requirements
What your server needs
  • PHP Version 8.3
  • MySQL 8.0+ or MariaDB 10.6+
  • BCMath, Ctype, cURL, DOM, Fileinfo, GD
  • JSON, Mbstring, OpenSSL, PCRE, PDO, pdo_mysql
  • Tokenizer, XML, Filter, Hash, Session, Zip
  • Composer
  • Nginx or Apache with mod_rewrite
  • allow_url_fopen() enabled
Upload Files
Place the app in your web root

  • Extract the downloaded package. Inside you'll find a Files folder.

  • Move everything from Files/ into your site's root (the directory your domain points to). Keep index.php and .htaccess at the root.

  • Run Composer to install PHP dependencies: 

cd /path/to/your/site/root/Files/core
composer install --no-dev --optimize-autoloader
Set storage permissions
cd /path/to/your/site/root
chmod -R 0775 core/storage core/bootstrap/cache
chown -R www-data:www-data core/storage core/bootstrap/cache
Create the Database
MySQL / MariaDB

Create an empty database and a user with full privileges. The installer will import its own schema, so the database must start empty. 

mysql -u root -p
CREATE DATABASE changalab CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'changalab'@'localhost' IDENTIFIED BY 'StrongPassword123';
GRANT ALL PRIVILEGES ON changalab.* TO 'changalab'@'localhost';
FLUSH PRIVILEGES;
EXIT;

Note these credentials — you'll enter them in the installer.

Run the Easy Installer
Browser-based setup

Visit the installer in your browser: 

http://your-site-url/install

Steps

  • Check requirements & folder permissions (all green).

  • Enter database details: host 127.0.0.1, port 3306, name/user/password you created above.

  • The installer imports the database automatically.

  • Set your admin email, username and password.

Note: if import fails with "Problem Occurred When Importing Database!", the database isn't empty — drop and recreate it, then retry.

Activate the License
Required to run ChangaLab

After installation, the first visit shows the activation page. Provide your Envato / purchase details to verify the license with ViserLab's server.

  • Purchase Code: find it in your Envato/CodeCanyon download page ("License certificate").

  • Envato Username: the account that bought ChangaLab.

  • Email: used for future communication & updates.

The provided info is sent to ViserLab for verification only — no sensitive data is collected. Once verified, the system is ready to use.

Web Server
Point the document root to index.php
Nginx (recommended)
server {
    listen 80;
    server_name your-site-url;
    root /path/to/site/root;
    index index.php index.html;

    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }
    location ~ \.php$ {
        include snippets/fastcgi-php.conf;
        fastcgi_pass unix:/run/php/php8.3-fpm.sock;
    }
    location ~ /(core|storage|vendor)/.*\.(php|env|json|lock)$ { deny all; }
}
Apache

Make sure mod_rewrite is enabled and the shipped .htaccess stays at the root. Set DocumentRoot to the site root.

Troubleshooting
Fix common local-install issues

Storage permission errors during install.

Run chmod -R 0775 core/storage core/bootstrap/cache and ensure the web server owns them.

"Database not empty" on import.

Drop and recreate the database, then run the installer again.

Activation fails / invalid purchase code.

Confirm the code is copied exactly and the domain matches the licensed URL. One license = one domain.

500 error after moving files.

Run composer install in Files/core and check that .env exists with correct DB credentials.
